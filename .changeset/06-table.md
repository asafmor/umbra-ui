**Table.** `DataTable`: sorting, row selection, groups, pinned columns, cell widgets, columns that hide by priority as the table narrows, keyboard navigation, server-side sorting and loading more at the end, columns the end user can show, hide, move, pin and resize (`columnState`, plain JSON an app can save), and a `height` of `"fill"`, `"content"` or pixels. Column helpers: `numberColumn`, `actionsColumn`, and `sparklineColumn` from `umbra-ui/charts`.
